# 🌐 Portfolio

A responsive personal portfolio website built using **HTML and CSS** to showcase my profile, education, skills, and projects.

🔗 **Live Portfolio:** https://kanduriavinash.github.io/Portfolio/

---

## 📌 About the Project

This portfolio website is designed to provide a simple and interactive way to learn about me, my technical skills, education, and interests.

The website focuses on:

* Clean and responsive UI
* Interactive hover and transition effects
* Structured navigation
* Personal information and education
* Technical skills visualization
* Contact and collaboration section

---

## ✨ Features

### 🏠 Home

Provides an overview of my profile and portfolio.

### 👨‍💻 About

Contains information about me and my interests.

### 🎓 Education

Displays my educational background from school to B.Tech.

### 🛠️ Skills

Showcases my technical skills using visual progress bars.

### 📩 Contact

Provides a way to connect and collaborate with me.

### 📖 More

Includes a user guide explaining how to navigate the portfolio.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Kanduriavinash/my-portfolio.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd my-portfolio
```

### 3. Run the website

Open `index.html` in your browser.
